02 · RDS 附加存储卷支持自动扩容：分别设置容量上限

事件简介：Amazon RDS 为 Oracle 和 SQL Server 的附加存储卷增加自动扩容。原先主卷可自动增长，附加卷则需人工预估和配置；最多三个附加卷可把总容量扩到 256 TiB，此次变化补齐这些卷的容量管理。

技术机制：用户为每个附加卷设定最大存储限制，服务持续监控实际用量，在接近已配置容量时自动向上扩展。新建与现有数据库实例均支持，可通过控制台、CLI 或 RDS API 开启。

限制与来源：AWS 称扩容无停机、功能本身不另收费，但仍按已配置存储资源计费，不能理解为免费增加容量。范围限公告列明的两种引擎，覆盖商业区及美国 GovCloud；公告未给出缩容能力或具体触发阈值，本期不补写。

03 · Aurora PostgreSQL 增加后量子密钥交换：客户端支持与协议版本都要核对

事件简介：Aurora PostgreSQL 兼容版增加后量子 TLS 密钥交换选项，用于保护客户端到数据库的传输。TLS 是加密连接协议；本次改变握手时建立共享密钥的方式，区别于本周已报道的 Serverless 计算容量扩展。

技术机制：18 及以上版本允许动态修改集群参数 ssl_groups，无需重启。白名单包含 X25519MLKEM768 等把传统椭圆曲线与后量子 ML-KEM 结合的组；服务端按列表顺序选择客户端同样支持的首个组。

实际影响：编辑判断：需要迁移数据库连接加密标准的团队，可先盘点驱动支持，再在参数组中配置并验证实际协商结果，减少把“服务已支持”误当成“现有连接已使用”的验收遗漏。

限制与来源：默认组仍为 prime256v1:X25519。ML-KEM 组要求 TLS 1.3；官方要求强制使用时设置最低协议为 TLSv1.3，并说明某些 TLS 1.2 RSA 握手会忽略 ssl_groups。它不是存储加密或证书签名算法的全面替换。

事件简介：Grafana 发布 13.3，其中跨仪表盘变量进入公开预览。变量常用于选择环境、区域或集群；此前同一选择器散落在多个仪表盘，修改配置时容易遗漏，造成各页查询范围不一致。

05 · Cloudflare 三季度 DDoS 报告：短时小流量攻击更需要及时处理

事件简介：Cloudflare 发布第三季度分布式拒绝服务攻击报告，即利用大量请求耗尽目标资源的 DDoS。窗口内的新信息是季度分析；数据覆盖七至九月，不能视为过去一天新发生的攻击。

技术机制：其网络记录的 1,820 万次网络层攻击中，96% 不足十分钟、98% 低于 1 Gbps。DNS 放大攻击环比增长 215%：攻击者伪造受害者地址发出小查询，让开放解析器把更大的响应送往受害者；一般 UDP 洪泛占比也明显上升。

实际影响：编辑判断：网站和网络团队除评估极大流量承载，还应检查短时突发能否自动识别、限流，以及是否存在开放反射服务。大量攻击在人工读到告警前已结束，仅靠事后响应可能错过处置窗口。

限制与来源：上述比例来自 Cloudflare 所见及所缓解的流量，不是全网普查。超 1 Tbps 攻击由二季度 805 次降到 251 次，与执法行动同期出现，文章提出可能关联，未证明单一因果；不能据此降低所有业务的防护容量。

技术特点：默认先以 TCP 连接测试延迟，再按延迟和丢包条件过滤，逐个测试候选地址下载速度并排序。HTTPing 模式改用 HTTP 请求，也可从响应头识别地区；并发、端口、测试时长及速度下限都能通过参数指定。
