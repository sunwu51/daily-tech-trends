窗口内官方更新 · 文件传输鉴权

AWS Transfer Family 经 NLB 保留 SFTP 客户端源 IP

事件简介：AWS Transfer Family 现在可在 VPC 托管的 SFTP 端点前使用自有 Network Load Balancer 时保留客户端源 IP。过去 NLB 会把连接地址替换为自身私网 IP，日志和事件看不到真实来源，自定义身份提供者也无法依据来访地址授权。

技术机制：新能力通过 Proxy Protocol v2 把原始连接信息从 NLB 传给 Transfer Family；启用后，真实源 IP 同时进入服务日志、事件与认证请求。开关按 Transfer Family 服务器设置，可经控制台、CLI 或 API 配置，不要求为整个账户统一切换。

实际影响：企业把合作方 SFTP 放在自有 NLB 后时，可继续使用固定来源网段做访问控制，并让审计记录指向真正客户端，而不是负载均衡器。它修复的是网络身份传递，不替代密钥认证、用户隔离或传输内容检查。

限制与来源：仅适用于 NLB 后的 VPC 托管 SFTP 服务器，必须正确配置并信任 PPv2 链路；公告没有提供迁移失败或伪造头部的测试数据。来源：AWS 公告与用户指南

窗口内官方更新 · 批处理运维

AWS Batch 增加批量取消与终止 API

事件简介：AWS Batch 新增 CancelJobs、TerminateJobs 与 TerminateServiceJobs，一次调用最多处理 50 个作业，并在同一响应中返回逐作业结果。此前大规模队列清理通常要由客户端循环调用单作业接口，自行处理部分失败和请求节流。

技术机制：CancelJobs 面向 SUBMITTED、PENDING、RUNNABLE 状态；两个 Terminate 接口覆盖包括 STARTING、RUNNING 在内的任意状态，也支持 array job。配套的 ListJobs 新增 isCancelled、isTerminated，服务作业列表则返回终止标记，便于控制器核对最终状态。

实际影响：训练或渲染批次发现坏输入时，平台可按 50 个 ID 一组停止整批任务，并直接记录每个结果，减少请求编排与补偿代码。批量接口缩短操作路径，但不会自动决定哪些作业应该终止，调用方仍需保证筛选和重试幂等。

限制与来源：单次上限 50 个 ID；取消与终止适用状态不同，且逐项失败仍须处理。公告未给出吞吐、速率配额或费用变化。来源：AWS 公告

BrowserSkill：让 Agent 借用已登录浏览器而不接管全部窗口

简介：腾讯 BrowserSkill 是本地浏览器桥接工具，面向能调用 shell 的编码 Agent。它让 Cursor、Claude Code、Codex 等复用用户已经登录的 Chrome 或 Edge，在单独可见的 Agent 窗口里浏览；若确需操作用户现有标签页，必须显式借用并在完成后归还。

技术特点：Agent 调用 bsk CLI，CLI 经本地 IPC 交给守护进程，再由回环地址 WebSocket 把请求送到扩展；扩展只自动化 Agent 窗口。验证码、登录或确认步骤可暂停请求人工接管，借用确认和求助能力由浏览器配置保存，旧命令行参数不能越过这些开关。

限制与来源：正式支持 Chrome、Edge；Firefox 尚在计划中。CLI、守护进程与扩展需保持协议兼容，沙箱会回收后台进程时还要在宿主机常驻 daemon；授权后的浏览器操作仍具有用户权限。来源：README：架构与自动化设置
