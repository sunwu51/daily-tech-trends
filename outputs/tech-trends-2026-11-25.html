01 · CloudFormation 扩充资源覆盖：把手工创建的对象纳入模板

事件简介：AWS 为 CloudFormation 增加覆盖八十八项服务的二百零六种资源类型，包括 SageMaker Hub、AgentCore PolicyEngine 和 EC2 Snapshot。CloudFormation 用模板描述并创建云资源；本次变化让更多原来需要另行操作的对象进入同一部署流程。

技术机制：模板记录资源属性，服务据此处理创建与依赖关系，同一模板可重复部署。Cloud Control API 同步支持这些新增类型，另增覆盖九十九项服务的二百二十四种只读资源类型，供发现、检查既有对象；只读支持不能当作完整创建和更新能力。

实际影响：编辑判断：平台团队将模型策略与计算资源一同交付时，可先核对新增类型，再把原来部署后手工补建的对象写进模板，让评审能看到它们的配置变化，减少遗漏和环境差异。

限制与来源：可用性仍取决于底层服务所在区域。AWS 称采用内部 AI 框架加快接入，但没有披露足以复现的算法或准确率，不能把覆盖数量理解为所有资源属性均已支持；具体对象仍需查类型参考。

02 · Agent Retrieval 公共预览：返回可定位到页码与视频片段的检索结果

事件简介：Google 介绍 Agent Retrieval 新增的托管导入与 SearchDocuments，现为公共预览。开发者将 Cloud Storage 中的文档或视频交给数据存储，服务处理解析、切分和向量编码，查询返回带来源位置的片段，供代理引用。

技术机制：文档可按页或文本块切分，SearchDocuments 合并语义与全文检索结果，并可再排序。视频使用独立 VIDEO 存储、按固定时间窗切分；显式启用音频编码后，还能按讲话内容查到时间段，不只匹配画面。

实际影响：编辑判断：为年报和培训录像做问答时，团队可少维护两套解析与索引流水线，将人工核对直接落到文件页码或录像时间。返回的是证据片段，最终答案仍需应用组织和验收。

限制与来源：目前仅 us-east4、europe-west4，接口为 REST v1beta；视频不支持结果再排序，默认不编码音频。预览期导入免单独收费，底层 Collection 仍计费；示例九分钟导入文档、亚秒检索均为官方小样本自测。

03 · Bonsai 2.5 27B：三值模型加强长工具链任务，运行时版本也要匹配

事件简介：PrismML 发布基于 Qwen3.8 27B 的 Ternary Bonsai 2.5 27B，面向本机编码与私有文件代理。新版重点改善连续工具调用、失败后的调整及重复思考，权重采用 Apache 2.0；不是仅将旧模型换一个下载格式。

技术机制：语言模型权重只取负一、零、正一。最紧密的 PTQ1_0 打包约为 5.93 GB；运行时还须对中间数值执行匹配的 Hadamard 变换，不能只识别 GGUF 文件格式。这个文件当前使用 PrismML 构建，普通 llama.cpp 的兼容文件是更大的 Q2_0，要求 b11556 或更新。

实际影响：编辑判断：本地仓库助手可在较小权重占用下尝试多轮查文件、改代码和运行测试，减少为容纳全精度权重而换高显存设备的需求；仍需用真实仓库验证完整任务。

限制与来源：5.93 GB 仅指语言权重，不是整套应用总内存。27B 的 MLX 包当前仅文本。SWE-bench Verified 从 60.8 到 75.6 是厂商评测，仍低于其全精度基线 80.6，不能概括为无损压缩；旧运行时可能加载成功却输出乱码。

06 · Safari 高刷新率实验：把输入采样与画布呈现分开处理

事件简介：开发者 Rida F’kih 展示在支持 ProMotion 的 iPhone 上实现接近 120 Hz 网页交互的实验。普通页面的 requestAnimationFrame 与触摸事件可能受六十赫兹限制；只提高 JavaScript 循环频率，未必能让用户看到更多帧。

技术机制：输入端借原生滚动区域取得合成线程处理的位移，并组合定时读取、空动画循环等手段提升采样。输出端用 transferControlToOffscreen 将 canvas 交给 OffscreenCanvas，利用当前 WebKit 占位画布提交路径，绕开等待普通页面绘制的节奏。

实际影响：编辑判断：需要跟手拖动或着色器效果的局部组件，可分别验证输入与呈现瓶颈，而不是只统计回调次数。作者用高速摄影记录三秒拖动，报告控制器方案平均 118 帧，普通指针方案六十帧。

限制与来源：这是作者特定设备上的实验，并非浏览器正式承诺。实现依赖当前内部行为，Apple 可以改变提交时机；部分技巧需额外滚动与动画。作者明确不建议据此重建整个应用，本期未复测耗电、设备覆盖和低电量表现。
