06 · Ruff：把 Python 检查与修复接入同一配置，但保留语义边界

简介：astral-sh/ruff 是 Rust 编写的 Python 代码检查器和格式化工具，服务于编辑器、提交前检查与持续集成。ruff check 找出问题，ruff format 调整排版；可通过 pip 或 uv 安装，无需把业务代码改写为 Rust。

技术特点：常用 Flake8 插件规则被直接用 Rust 重新实现，配置放在 pyproject.toml 或 ruff.toml，内置缓存避免重查未变化文件。自动修复另分 safe 与 unsafe：例如把取列表首元素改为迭代器，空集合时异常类型会改变，因此归入后者。

适用场景与价值：编辑判断：维护多目录 Python 工程时，可将导入清理、规则检查和排版纳入同一套命令，减少协调多个插件配置的工作；先明确规则集，再逐批迁移，比直接打开所有规则更容易评审改动。

限制与来源：默认仅应用标为安全的修复，unsafe 修复可能改变行为或移除注释，须显式启用；预览功能仍可能变化。十至百倍速度是作者基准，不能外推为完整构建提速，也不能以静态检查替代业务测试。
