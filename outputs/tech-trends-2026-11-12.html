01 · Apache HTTP Server 2.4.71：修复 HTTP/2 并发处理中的远程执行漏洞

事件简介：Apache 发布 HTTP Server 2.4.71，修复三项漏洞，其中 CVE-2026-119618 为关键级别。它影响 2.4.55 至 2.4.70 的 HTTP/2 模块；这次修复针对网页服务器处理网络请求的入口，与昨日 Git 的仓库输入漏洞不同。

技术机制：mod_http2 的 assign_headers() 在多线程共享资源时同步不当，可造成堆内存损坏并进一步导致远程代码执行。官方还列出 mod_md 空指针崩溃，以及 mod_vhost_alias 单字节栈越界修复，三者的受影响版本不同。

实际影响：编辑判断：运维团队应核查实际承接 HTTP/2 的服务器和容器镜像，再安装补丁并验证加载的模块版本；只检查前端代理是否更新，可能遗漏后方仍可直接访问的服务。

限制与来源：独立 mod_h2 的受影响范围为 2.0.8 至 2.0.42。Wiz 二手表格的修复版本与其正文矛盾，本项采用 Apache 官方范围，不转述该数字。Wiz 称发表时未见在野利用，不能据此证明之后没有攻击。

02 · Meta Intelligent Delivery：把额外算力分给最可能受益的请求

事件简介：Meta 披露广告投放中的 Intelligent Delivery：在容量和延迟预算有限时，预测哪些请求值得增加计算，再调整区域、硬件和排序工作量。本次是运行机制披露，区别于昨日 TLX 的内核流水线，以及用户偏好如何传入推荐链路。

技术机制：Resource Core Model 在候选检索前运行一次，含六十亿稀疏参数与两千万稠密参数，派生模型分别预测收益、计算消耗和延迟。区域流量按分钟调整，工作负载按实测效率匹配硬件，主机内再在尾延迟目标下削减低收益的昂贵工作。

实际影响：编辑判断：多阶段推理服务可先测量增加候选数的收益与成本，再决定给哪类请求扩算力，减少给所有请求统一增加预算的浪费。区域迁移会改变主机负载，因此需要端到端闭环测试。

限制与来源：累计约一成排序增益及代理贡献比例均为 Meta 自报。代理提出并测试配置后仍由工程师批准；跨所有阶段的单模型实时决策仍是方向，不能写成已完全自动优化。

08 · Meerkat 的 QuePaxa 选择：领导者失效时让其他提议者接续

事件简介：Cloudflare 解释实验性全球控制平面服务 Meerkat 为何采用 2023 年提出的 QuePaxa 共识算法。共识让多个副本确认同一事件日志；跨洲网络延迟波动时，严格依赖领导者的系统可能停在故障检测和重选阶段。

技术机制：提议者给方案分配优先级，记录者传播所见方案，其他提议者改采较高优先级，促成收敛。领导者保留一次往返的快速路径，但客户端等待短暂对冲超时后可联系其他副本，不必先确认领导者已经死亡才能继续推进。

实际影响：编辑判断：跨洲配置服务可用额外消息开销换取领导者失联时继续处理请求的机会；缩短对冲时间会增加提议者及网络流量，不是无成本提高可用性。

限制与后续观察：这是新工程披露，不是成熟替代品发布。作者仍在把崩溃停止设计扩展到崩溃恢复，并进行形式验证；应跟踪验证结果、故障注入和恢复后的尾延迟。文中不停顿曲线来自自测，不能外推任意网络分区。
