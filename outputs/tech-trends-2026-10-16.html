Rust 1.99.1：修复链接缺符号与跨语言布尔返回值

事件简介：Rust 发布 1.99.1 补丁版，修复此前版本的三类回归，涉及 UEFI 等目标的链接、x86_64 跨语言调用，以及 macOS 的链接器启动。它针对已有程序可能编译失败或读到错误返回值的问题，可通过 rustup update stable 获取。

技术机制：LLVM 的循环优化可能把代码转换为 wcslen 调用，部分目标却没有该函数；补丁在 compiler-builtins 中补上后备实现。外部函数接口（FFI）的 bool 返回值重新按 ABI——二进制调用约定——要求做零扩展，避免返回寄存器高位残留造成非 0/1 值；macOS 的 rust-lld 则加入寻找 libLLVM 的运行时库路径。

实际影响：编辑判断：维护 UEFI 程序或 C/Rust 混合库的团队，应重跑链接与边界值测试，核对实际受影响目标；这次修复的价值是恢复既定行为，不能用来推断常规代码性能提升。

限制与来源：公告未将这些回归定性为安全漏洞，也未声称覆盖所有 FFI 问题。应按自身目标与工具链复验；以上变化来自 Rust 发布团队。

Gateway Forward 公测：在真实 HTTP 请求路径里运行自定义代码

事件简介：Cloudflare 为安全 Web 网关推出 Forward 动作公测：已有 HTTP 策略允许的流量，可再按匹配规则交给 Workers 处理。它面向需要改写请求、响应或生成自定义访问提示页的安全团队，而不只是发送一条事后告警。

技术机制：首条匹配的 Forward 规则把请求交给绑定的 Worker；中间件读取头部、正文与网关上下文，调用 next(request) 访问上游，再处理响应。网关继续负责 TCP、TLS 和 HTTP 版本协商，自定义代码只负责转换逻辑；两者共处基础设施，厂商称分发无需新增网络跳转。

实际影响：编辑判断：需要给敏感网站增加“说明访问用途”页面的企业，可由 Worker 返回表单、用 KV 保存有期限的会话，并把身份与理由记入 D1，减少为这一流程单独维护代理服务器的工作。

限制与来源：Forward 仍为公测，Worker 执行耗时会影响体验，请求按 Workers 计费且受所用计划限制。作为规则条件返回类型化值的 Gateway Custom Functions 尚待年底前提供，不能把它写成已上线能力。

Adaptive Metrics 自动应用正式可用：先降序列，再决定恢复多少细节

事件简介：Grafana Cloud 宣布 Adaptive Metrics 的自动应用功能正式可用，并增加 cost-first 模式。该服务根据查询使用情况建议聚合指标，减少活跃时间序列——即不同指标名与标签组合——的数量；此前自动执行只支持优先满足查询细节的 coverage-first。

技术机制：cost-first 先应用预计减少序列的建议，再把增加序列的建议按增量从小到大排序，直到下一项会超过本轮起始总量便停止。coverage-first 则直接应用全部建议，包括恢复已聚合指标的完整分辨率。团队可按环境、集群等维度分段，为不同数据选择模式。

实际影响：编辑判断：给 AI 代理开放大范围指标查询的团队，可对试验环境启用 cost-first，避免一次误查就自动恢复大量序列；核心业务则保留 coverage-first，让确实使用的数据尽快恢复细节。

限制与来源：约束基于每轮预测序列数，并非对全部账单金额的硬上限。cost-first 可能暂不恢复某些细节，需要人工审查；启用要求 Admin 权限，官方建议先给不能丢失的数据设置豁免。
