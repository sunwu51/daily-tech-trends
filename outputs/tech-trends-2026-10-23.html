01 · PHP2Shell 修复进入 Docker 镜像：更新运行环境，而非只更新应用代码

事件简介：Docker 公布 PHP2Shell 对容器用户的影响，称官方镜像与 Hardened Images 均已更新。PHP 8.2.35、8.3.36、8.4.27、8.5.12 修补两项可导致远程代码执行的核心漏洞；旧版 PHP 也受影响，不能因应用运行在容器内便忽略。

技术机制：一项漏洞发生在请求内存耗尽后，清理逻辑读取未完成初始化的数据；另一项由致命错误留下跨请求的失效指针，后续请求使用已释放内存。PHP 基金会确认特定 mod_php 与 PHP-FPM 路径的利用条件，问题位于内存管理及错误处理。

实际影响：编辑判断：使用 PHP 基础镜像构建服务的团队，应拉取修复镜像、重新构建并部署，再核对运行中的 PHP 版本；仓库标签更新不会自动替换已有容器。

限制与来源：Docker 将升级列为完整缓解路径；不能把容器隔离当成漏洞修复。镜像更新时效来自 Docker 自报，根因和修复版本另由 PHP 基金会交叉确认。

03 · OpenSearch Serverless 默认五秒刷新：缩短新文档进入检索的等待

事件简介：Amazon OpenSearch Serverless 将下一代搜索与向量集合的默认刷新间隔从十秒降到五秒，自动生效，无需用户改配置。刷新决定新写入文档何时能被搜索，并不是单次查询的响应耗时。

限制与来源：五秒是默认刷新间隔，公告未给出端到端可见性时延保证，也未提供吞吐或成本对照。采集、嵌入生成和应用缓存仍可能带来额外延迟，应以实际写入到查得的测量验收。
