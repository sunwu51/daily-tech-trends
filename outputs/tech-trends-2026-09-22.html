当前 GitHub Trending · 移动安全取证

MVT：从移动设备提取入侵迹象

简介：Mobile Verification Toolkit（MVT）是 Amnesty International 开源的移动设备取证工具，服务调查人员和安全响应团队，用于检查 Android 与 iOS 设备是否留下潜在入侵证据。它从备份、文件系统或设备采集数据，输出可供分析的检测结果。

技术特点：项目把取证流程拆成 Android 和 iOS 命令行模块，使用已知恶意域名、文件和行为指标匹配采集结果，并支持生成时间线和 JSON/CSV 等报告。README 同时区分完整文件系统取证、加密备份和普通备份的权限边界，避免把一次扫描当成确定性结论。

适用场景与价值：响应团队可以先对涉事手机备份做批量指标匹配，再把命中项交给人工复核，减少逐文件排查的时间；取证记录也更容易进入案件或事件响应流程。

限制与来源：需要设备权限、合适的备份或越狱/Root 条件，指标库覆盖不等于无命中就是安全；项目明确面向专业调查。来源：MVT README

窗口内官方发布 · Kubernetes 1.37

PVC Last Used Time：让存储清理有使用依据

事件简介：Kubernetes v1.37 将 PersistentVolumeClaimUnusedSinceTime 特性门控提升为 Beta 并默认启用。PersistentVolumeClaim（PVC）保护控制器会为 PVC 增加 Unused 条件，告诉运维当前是否仍被运行中的 Pod 引用。

技术特点：控制器直接在 PVC API 状态中维护使用条件，运维工具无需再跨对象查询 Pod 与卷的关系；官方示例展示了用字段筛选长期未使用声明的方式。它提供的是观测信号，不会替用户自动删除数据。

适用场景与价值：集群管理员可把 Unused 状态接入报表和人工清理流程，先识别孤儿存储再确认保留策略，降低误删仍在使用卷的风险。

限制与来源：Beta API 仍可能调整，Unused 只反映运行中 Pod 引用关系，不能替代备份和业务确认。来源：Kubernetes 官方博客

窗口内安全公告 · Rust CI

Miri 缓存环境变量导致 GitHub Actions 泄露风险

事件简介：Rust 安全响应团队披露，Miri 会把环境变量写入 target/，而 GitHub Actions 缓存该目录后，来自不可信 Pull Request 的工作流可能读到主分支缓存中的秘密。问题出在工具输出与 CI 缓存策略组合，而非单一依赖漏洞。

技术特点：风险路径是主分支写缓存、PR 只能读取缓存；若缓存目录含凭据，恶意 PR 可通过构建步骤读取。公告建议停止缓存相关目录或清除受影响缓存，并审查令牌权限。

适用场景与价值：维护 Rust 项目的团队应把该案例加入 CI 审计清单，区分可缓存编译产物与含环境信息的目录，降低第三方 PR 触达秘密的机会。

限制与后续证据：影响取决于工作流是否缓存 target/、秘密注入方式和分支权限；应继续关注修复版本、受影响项目范围及官方缓解建议。来源：Rust Security Response
