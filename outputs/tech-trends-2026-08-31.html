教育生成 / 早期产品

Academa 把 STEM 讲义写成代码再生成可维护视频

发生了什么：Academa 展示 66 个 STEM 讲座，并允许用户请求约 25 分钟生成一段新课。团队把讲义动作（旁白、绘图、公式）表示成代码，再由 LLM 生成视频。

技术核心：“lecture videos as code”让内容可以像软件一样修订、翻译和个性化，目标是支持交互式问答与按学习进度重编译课程。

为什么重要：把长视频变成可编辑中间表示，有机会降低小众主题内容维护成本，也便于审阅具体公式和图形步骤。

成熟度/风险：当前仍是创业团队展示，生成时延、事实校验、配音与图形质量尚缺独立基准；教育使用需要教师复核。

来源：产品与技术说明 · HN 讨论

浏览器供应链 / 安全事件

恶意扩展通过更新窃取钱包、会话和浏览历史

发生了什么：BleepingComputer 援引 Socket 调查称，19 个 Chrome/Edge 扩展被收购后通过自动更新植入模块；其中一个扩展曾有至少 7 万 Chrome 用户和 1 万 Edge 用户。

技术核心：恶意代码用加密 WebSocket 连接 C2，移除 CSP、注入脚本，并针对 EVM/Solana/Tron 钱包、交易所会话、表单输入和 ClickFix 诱饵执行不同模块。

为什么重要：商店审核无法替代扩展更新链审计；企业应锁定扩展清单、监控权限和更新来源，并准备会话吊销。

成熟度/风险：Google 已移除 Chrome 版本，但报道时部分 Edge 版本仍存在；这是单一行动披露，受影响 ID 与 C2 域名应按原文逐项排查。

来源：调查报道 · Socket 研究入口

语音与音乐交互 / 项目新建

midi-voice 用浏览器语音指令驱动硬件合成器

发生了什么：项目通过浏览器麦克风和 Web Speech API 转录语音，让 Sonnet 4.6 将指令解释为 MIDI 工具调用，再由 Web MIDI API 输出到 Roland Juno-D；还规划共享时钟循环器。

技术核心：无需本地桥接守护进程，Next.js 16 应用直接控制 MIDI；语音命令可叠加鼓、贝斯和风琴声部，并保留和弦、滤波器、混响等手动控件。

项目状态：project_new；13 Stars、1 Fork，创建于本窗口内。

成熟度/风险：依赖 Chromium 的 Web MIDI/Web Speech 支持与 Anthropic API，且仅在 Juno-D 等设备上测试；语音误识别可能触发错误 MIDI 操作，应提供权限提示和急停。
