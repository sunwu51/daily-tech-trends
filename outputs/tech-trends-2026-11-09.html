01 · MuJoCo：先编译关节模型，再反复运行物理仿真

简介：google-deepmind/mujoco 是面向机器人、生物力学及机器学习研究的通用物理引擎，模拟关节结构与环境接触。开发者可用 C 接口或 Python 绑定驱动实验，也能在桌面与浏览器查看模型和运动。

技术特点：内置 XML 编译器预先分配低层数据结构，运行时直接在这些结构上推进仿真，并提供计算物理量的辅助函数。Python 包自带引擎；仓库另给出多线程 rollout，即批量推进多条运动轨迹的教程。

适用场景与价值：编辑判断：研究机械臂控制时，可先描述关节与接触对象，再用同一模型比较不同控制输入，减少自行编写动力学与可视化程序的准备工作。仿真结果仍须与实际设备校准。

限制与来源：当前 Python 入口要求 3.11 以上；官方推荐版本化二进制，main 分支可能不稳定。浏览器 WebAssembly 版本明确慢于原生 C，不能拿浏览器体验推断训练吞吐；项目也声明并非获官方支持的 Google 产品。

02 · SmartDNS：比较解析地址的可达速度，而非只比回答先后

简介：pymumu/smartdns 是运行在本地网络的 DNS 域名解析服务器，供路由器、树莓派等设备为客户端选择访问地址。它并发查询多个上游，再检测返回地址从本地访问的速度，也支持指定域名地址与广告过滤。

技术特点：多个上游返回的 IP 进入测速与优选流程；启用缓存时，未命中可先返回一个地址并设短有效期，后台收齐结果后保留速度相近的优选地址。双栈优选还可在 IPv4 明显更快时抑制 IPv6 回答。

适用场景与价值：编辑判断：同一网站在不同网络线路表现不同时，可让局域网客户端共用这套选择机制，减少逐台手改地址的操作。它关注终端访问选路，与本周 Cloudflare 的权威 DNS 配置构建属于不同问题。

限制与来源：默认向全部已配置上游发请求，上游仍可能记录查询；FAQ 建议可信上游、加密传输及分组。过期缓存可能使动态域名换址后访问失败，可按域关闭。README 的五倍速度仅是作者单例。
