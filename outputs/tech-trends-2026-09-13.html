当前 Trending / 销售 CRM

DeskcommCRM：面向 WhatsApp 的开源 AI 销售系统

简介：DeskcommCRM 是可自托管的销售 CRM，面向通过 WhatsApp 获客的企业，在自己的 VPS 上运行应用、WhatsApp 连接和数据库。README 以 Next.js 16、TypeScript strict 与 Supabase（Postgres、Auth、Storage）为基础。

技术特点：内置 AI 代理用于接待、线索筛选和销售，WAHA 提供 WhatsApp 接入，系统按多租户设计并预留 MCP。HostGator setup kit 将整套服务用一个命令部署，CI 和生产 runbook 也在仓库中。

适用场景与价值：小型销售团队可把聊天记录、联系人和自动跟进放在同一套自有服务器里，减少 SaaS 月费和跨系统复制线索的工作；这是基于 README 能力的编辑判断。

限制与来源：WhatsApp 账号合规、WAHA 稳定性、模型费用和多租户隔离仍需部署方验证；README 未提供独立转化率数据。来源：官方 README

当前 Trending / 交易代理

CloddsBot：预测市场与加密市场的自托管 AI 终端

简介：CloddsBot 是基于 Claude 的 TypeScript/Node.js 交易终端，面向希望自行运行代理、监控预测市场、加密货币和期货的用户，要求 Node.js 22 以上。

技术特点：README 描述 121+ skills、1000+ 市场连接，代理可扫描机会、执行订单并管理风险；覆盖 Polymarket、Kalshi、Binance、Hyperliquid、Solana DEX 与多条 EVM 链，并提供 WebChat 和快速启动配置。

适用场景与价值：研究者可在统一终端回测或观察多个市场，避免为每个交易所分别维护 API 轮询和下单脚本；自托管也让密钥留在自己的运行环境。

限制与来源：这是高风险自动交易软件，README 的市场数量和克隆数是作者陈述，不等于收益或安全保证；密钥权限、滑点、合规和故障止损必须另行审计。来源：官方 README

MathModelAgent：把建模比赛流程封装成桌面 Agent

简介：MathModelAgent 面向数学建模参赛者，自动分析题目、建立模型、编写并纠错代码，最后生成可提交论文。官方提供 macOS（Apple/Intel）和 Windows 64 位桌面安装包。

技术特点：桌面版内置 Claude Code 与 MathModelAgent SKILLS，不要求用户另装 Python、Node.js 或 Redis；代码解释器可选本地 Jupyter notebook，或 E2B、Daytona 云端环境，多代理分工建模、编程和论文。

适用场景与价值：参赛者可从题目直接进入可编辑 notebook 和格式化论文，减少临时搭环境、拼接脚本和手工排版的时间；本地解释器还保留后续复现实验的文件。

限制与来源：Windows 安装包当前未签名，可能触发 SmartScreen；模型 API key、云解释器费用和生成论文的数学正确性仍需人工复核。来源：官方 README
