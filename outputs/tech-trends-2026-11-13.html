01 · Rust 1.100：依赖更新可设置等待期，类型升级仍须做兼容检查

事件简介：Rust 发布 1.100.0，稳定化 never type（永不产生值的类型，写作 !）、自定义分配器核心接口及 Cargo 依赖发布时间筛选。它既改变语言表达能力，也调整构建流程；可用 rustup update stable 更新。

技术机制：Cargo 在 .cargo/config.toml 设置 global-min-publish-age 后，解析依赖时跳过太新的版本；单次更新可显式绕过，选定版本随后由 Cargo.lock 保留。构建目录也把配置哈希移到父目录，减少不同特性组合或 Git 工作树共享缓存时的冲突。

实际影响：编辑判断：维护持续集成的团队可先用等待期避免立刻吸收刚发布的依赖，再评审锁文件变化；同时检查脚本是否依赖旧构建目录布局，减少缓存命中与产物路径判断错误。

限制与来源：缺少 pubtime 的索引记录不受等待期限制，cargo install 也忽略它。旧 edition 的 never type 回退由 () 改为 !，少数泛型代码可能失效；冷静期不替代依赖审查。本项是正式版本变化，区别于昨日 GPU 实验模块成果。

事件简介：Amazon Cognito 支持 OAuth 2.0 令牌交换标准 RFC 8693。这个登录与访问控制服务，现在允许代用户调用接口的服务或 AI 代理，把用户令牌换成专供某个下游服务使用的新令牌；此前需转发原令牌或自行维护签发逻辑。

技术机制：新令牌可缩小 scope 权限范围、绑定单一 audience 接收方，并且不附刷新令牌。请求若包含 actor token，Cognito 会写入 act 声明标识中间调用者；可通过令牌端点或新增 GetDerivedToken API 交换。

实际影响：编辑判断：MCP（模型上下文协议）服务器代用户查业务数据时，可先换取只面向该后台的凭证，让后台区分用户直访与代理代办，减少将原始广泛权限沿调用链传递的需要。这是具体授权接口，区别于本周跨机构代理身份倡议。

限制与来源：功能限 Essentials 与 Plus 方案，在 Cognito 已提供的区域可用。更窄权限仍需调用方正确设置，公告没有给出任意后端自动识别 act 的保证，也未提供独立部署效果数据。

05 · nvm：让不同项目在各自终端使用指定 Node.js 版本

简介：nvm-sh/nvm 是按用户安装、按 shell 会话生效的 Node.js 版本管理工具，面向同时维护多个 JavaScript 项目的开发者。它通过命令行安装、选择运行时，支持 Unix、macOS 及 Windows WSL 的 POSIX shell，不要求全机共用一个版本。

技术特点：nvm 以加载进 shell 的函数运行；项目根目录或父目录可放 .nvmrc，nvm use 和 nvm install 会向上查找并读取版本。前者切换已有版本，后者可安装缺失版本再切换；nvm exec 也可指定版本运行子 shell 命令。

适用场景与价值：编辑判断：开发者在旧服务与新前端之间切换时，可将准确版本写进各自仓库，再在对应终端执行 nvm use，减少反复卸载系统 Node.js 或记忆每个项目版本的操作。只写 node 或 lts/* 这类别名仍会随上游变化。

限制与来源：不直接支持 Fish；Windows 原生替代项目并非本仓库维护。非交互 Bash 不会自动加载普通配置，容器任务需显式安排加载；用户级安装也不会改变其他账户的版本，.npmrc 中 prefix 与它不兼容。

06 · Node.js：等待网络时让出执行机会，重计算仍需另作安排

简介：nodejs/node 是开源、跨平台的 JavaScript 运行环境，让开发者在浏览器外编写网络服务和命令行程序。安装运行时后，可用 node server.js 启动代码；内置 node:http 能接收请求、读取请求信息并写回响应，不必先引入网页框架。

技术特点：V8 执行 JavaScript，事件循环协调连接与回调；网络等异步输入输出等待返回时，不必为每个请求独占一个线程。libuv 工作线程池承担部分文件操作、压缩和加密任务，完成后再通知事件循环处理结果。

适用场景与价值：编辑判断：编写需等待多个后台接口的聚合服务时，可复用 JavaScript 技能，把等待时间留给其他连接，减少自行管理逐连接线程的工作。这是程序执行与调度机制，与上一项 nvm 选择运行时版本各有职责。

限制与来源：长时间 JavaScript 回调、同步文件接口或大型 JSON 处理仍会阻塞其他请求，异步语法不自动消除计算开销。README 明示 Alpha 和 Current 面向库作者与 CI，LTS 侧重稳定安全；本期不将当前上榜写成新版本发布。
