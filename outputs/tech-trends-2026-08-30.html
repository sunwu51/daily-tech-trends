图形渲染 / 项目新建

DLSS5-Feeder 用 ReShade 深度和运动向量接入神经渲染

发生了什么：新仓库让没有原生 DLSS 的 D3D11/D3D12 游戏构造 DLSS DLAA 合约：从 ReShade 获取帧和深度，从 LaunchPad 获取光流，再调用 DLSS 5 神经渲染并写回画面。

技术核心：D3D11 路径通过私有 D3D12 设备执行，D3D12 直接使用游戏设备；项目还提供 32 位游戏的辅助进程路径，整个流程嵌在 ReShade effect chain 中。

项目状态：2026-08-29 创建；70 Stars / 4 Forks。本条是 project_new，不是长期增长。

成熟度/风险：README 只报告少量游戏的端到端验证，并明确快速运动会出现 ghosting、薄几何变软且 HUD 一起处理；需要兼容性、性能和发行许可测试。

Agent 安全 / 独立研究

实验显示：自动模式分类器不能替代隔离环境

发生了什么：Embrace The Red 记录了一条从网站摘要、ZIP、模块遮蔽到远程 payload 的攻击链：Agent 拒绝运行可疑二进制，却在攻击者目录中执行自己写的 Python 解码器，触发恶意 struct.py。

技术核心：作者报告小样本下 60%（3/5）到 80%（4/5）的成功率，并观察到自动模式有时允许创建恶意进程，却阻止后续清理命令；文中也记录了使用 python3 -I、静态分析和安全工作目录时的拒绝案例。

为什么重要：“0.00%”只代表固定测试集，不能推出对未见攻击的安全保证。文章引用 Anthropic 将 Auto Mode 定义为尽力而为的分类器，真正边界仍是 OS 隔离和网络出口控制。

成熟度/风险：这是单篇研究者实验，样本小且攻击链经过迭代，不是普遍 ASR；但其模块遮蔽、间接提示注入和清理失败路径足以作为 Agent 运行环境的威胁建模用例。
