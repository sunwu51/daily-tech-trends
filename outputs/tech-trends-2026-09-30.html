CryptoLabe 用 Agent 建立后量子迁移所需的密码学资产图谱

事件简介：Cloudflare 介绍内部工具 CryptoLabe，用 AI Agent 扫描大量代码库，识别 TLS、JWT、SAML、自定义签名、硬件密码模块等密码学使用点，并把发现映射到后量子迁移任务。目标不是自动改写算法，而是先回答“哪里用了什么、由谁依赖、当前为什么不能迁移”。

技术机制：常规扫描按仓库运行提示词，产出可由负责人验证的发现；另一套“hard cases”提示会忽略普通 TLS，集中寻找尺寸受限字段、硬件内置算法、盲签名、自定义协议和外部依赖。系统把具有共同阻塞条件的发现归入 prerequisite，例如库或身份提供商尚未支持后量子 JWT。

实际影响：大型组织可先选择处理长期敏感数据或公网认证的关键仓库，生成密码学清单，再让系统负责人确认哪些路径仍在使用、哪些可由网络层补偿控制覆盖。这样能把抽象的后量子计划拆成库升级、标准成熟度和供应商支持等具体依赖。

限制与来源：Cloudflare 明确表示没有真值数据集，不能证明覆盖全部密码学使用；不同提示会发现不同问题，每项结果仍需熟悉系统的工程师复核。公开仓库只有选定提示词，并非完整 CryptoLabe 产品。来源：Cloudflare：扫描方法、阻塞条件与验证边界

Cloudflare 申请成为公共 CA，并计划发行 Merkle Tree 证书

事件简介：Cloudflare 宣布建设公共证书机构，已申请加入 Chrome、Apple、Microsoft 和 Mozilla 根计划，并签约收购一个自 2012 年起广泛受信的 GlobalSign 根。新 CA 尚未签发证书；现阶段是公开根计划审批、兼容性和运营设计。

技术机制：服务将以 ACME 自动签发与续期为入口，并要求客户端支持 RFC 9773 的 ACME Renewal Information，以便发生合规或安全事件时提前发布续期窗口、分批替换证书。Cloudflare 还计划公开签名软件的可复现构建、HSM 证明和运行状态，并在 2027 年第一季度尝试生产 Merkle Tree Certificates，减少后量子签名导致的证书链膨胀。

实际影响：网站运营者未来可能只需更换 ACME directory URL 就能增加一个免费自动化签发来源；对整个 WebPKI 而言，多一个大规模发行者可缓解免费证书供应过度集中的运营风险，并为经典证书与后量子证书并行迁移提供路径。

限制与来源：根计划批准、旧设备覆盖和正式签发时间尚未确定，GlobalSign 根收购也不等于立即获得所有平台认可；MTC 仍处标准和生态落地阶段。来源：Cloudflare：根计划、ACME、透明度与 MTC 路线

OpenShell：在内核与出口代理层执行 Agent 权限策略

简介：NVIDIA/OpenShell 是面向自主 Agent 集群的开源安全运行时。它让 Agent 安装软件、读写指定文件、调用 API 或使用 GPU，同时由管理员声明每个沙箱可访问的文件、系统调用、网络地址和凭据，适合需要运行不完全可信自动化代码的平台团队。

技术特点：每个 Agent 运行在隔离沙箱中，内核级控制检查文件访问与系统调用，所有外连经过策略判断。真实凭据不会暴露给 Agent，而是在请求发往获批端点时由提供器注入；策略变更应用前，prover 会分析新增主机、凭据或 API 方法权限，把高风险扩权交给人工复核。网关、supervisor 与沙箱组成控制和执行链。

适用场景与价值：企业可让编码 Agent 在临时环境中安装依赖、访问私有包源并提交结果，却不授予整个主机或云账户权限；同一网关还能通过 SDK 和 Kubernetes 管理多个沙箱。机制把“Agent 需要能力”和“不能看见所有秘密”拆开处理。

限制与来源：需要 Docker、Podman 或主机虚拟化；Windows WSL2 支持仍标为实验性，Kubernetes 部署要求 CNI 真正执行 NetworkPolicy。项目收集可关闭的匿名运营遥测，生产使用仍需自行验证策略和外部材料许可。来源：README：执行机制、平台要求与遥测、架构文档

RDS API 新增快照完整逻辑大小，区分增量占用与可恢复数据量

事件简介：Amazon RDS 在控制台和 DescribeDBSnapshots API 中加入 FullSnapshotSizeInBytes。它显示组成某个快照的全部数据块大小，包括当前快照直接保存的块以及从更早快照引用的未变更块。

技术机制：RDS 快照采用增量存储，后续快照只新增变化块，但恢复一个时间点仍依赖完整引用链。新字段表达该时间点的完整逻辑数据量，而不是本次快照新增并计费的增量字节；例如 100 GB 卷只写入 50 GB 数据时，完整快照大小显示 50 GB。

实际影响：备份平台和容量审计脚本可通过 SDK 或 CLI 获取统一指标，估算跨账户复制、导出、恢复测试和数据增长趋势，而不再把“本次增量很小”误解为恢复对象本身很小。控制台列也方便运维人员直接比较不同数据库快照。

限制与来源：该字段不是增量存储占用或账单金额，不能单独用于预测快照费用；共享块的生命周期和删除影响仍需结合 RDS 备份规则判断。功能覆盖所有商业区域和 RDS 实例。来源：AWS：字段语义与示例
