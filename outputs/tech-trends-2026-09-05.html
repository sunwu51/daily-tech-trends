当前 Trending / 技能包

mattpocock/skills：面向真实工程的 Agent 技能集合

简介：可安装到 Claude Code、Codex 等代理的工程技能文件，服务需要需求澄清、文档和代码流程的开发者；可作为普通文件编辑或只读插件更新。

技术特点：技能是小型 Markdown/脚本单元，安装器选择目标代理；初始化会询问 issue tracker、标签和文档目录，把流程规则放进项目版本库。

适用场景与价值：团队可将“先澄清再实现”装进新仓库，新成员用同一命令获得一致入口，减少口头传递流程。

限制与来源：README 称可适配任意模型，但 Codex 原生插件仍在路线图；安装前应审查脚本。

证据：官方 README

当前 Trending / Agent 约束

Ponytail：让代码代理优先采用最小实现

简介：装入 Claude Code 等代理的技能，引导开发者减少过度工程，例如优先使用浏览器原生控件。

技术特点：通过提示和示例约束“先检查平台能力再写代码”；作者在真实 FastAPI+React 仓库 12 个任务上报告平均少写 54% 行代码。

适用场景与价值：表单和简单交互可少装依赖、少写包装层，降低审查和维护面。

限制与来源：基准由作者运行，任务差异很大；应在自身代码库复测。

证据：官方 README

当前 Trending / Agent 工具链

ECC：把技能、记忆和安全检查组成代理工具链

简介：面向 Claude Code 及兼容代理的开源 harness，提供技能、命令、钩子和安全工具。

技术特点：安装器按代理选择组件，AgentShield 扫描密钥、危险模式和依赖风险，并通过 npm 包、GitHub App 等受控渠道分发。

适用场景与价值：多代理项目可统一部署审查、测试和研究步骤，减少仓库间配置差异；扫描可作为提交前额外检查层。

限制与来源：要求 Node.js 18+、Git 和 Claude Code 2.1+；扫描不能替代人工审查。

证据：官方 README

当前 Trending / 自托管 Agent

Hermes Agent：带学习循环和多渠道入口的代理

简介：可在本地、VPS、GPU 集群或无服务器环境运行，并从 CLI、Telegram、Discord、Slack 等渠道接收任务。

技术特点：用 FTS5 搜索历史会话，自动创建和改进技能，提供 cron、并行子代理和 Docker/SSH/Modal 等七种终端后端；模型可切换供应商。

适用场景与价值：夜间备份、报告或跨设备对话可放在云端运行，消息触发而无需笔记本常在线。

限制与来源：多渠道和远程后端扩大凭据与隔离面，需配置权限、沙箱和成本上限。

证据：官方 README

HydraFusion：按任务选择模型的编排流程

当前 Trending（中文）/ OCR

RapidOCR：可离线部署的多平台 OCR

简介：开源免费、支持多语言及 Linux/Windows/macOS 的 OCR 工具，默认中英文，提供 Python、C++、Java、C# 接口。

技术特点：将 PaddleOCR 模型转为 ONNX，再结合 ONNX Runtime、OpenVINO、MNN、TensorRT 等后端推理；也支持基于自有数据微调。

适用场景与价值：票据和扫描应用可在本地识别，按设备选择后端，减少跨环境集成工作。

限制与来源：语言和精度取决于模型列表；后续应观察 v3 模型在真实设备的基准。

证据：官方 README

窗口内 / Kubernetes 安全

Kubernetes 1.37：Rootless Kubelet 晋级 Beta

事件简介：KubeletInUserNamespace 让 kubelet、CRI/OCI runtime、CNI 和 kube-proxy 可在 Linux user namespace 下以非 root 运行。

技术机制：功能门控把节点组件置于 user namespace，降低主机 root 权限暴露。

实践影响：多租户集群可在测试节点评估 rootless 模式，减轻容器逃逸后的主机影响。

限制与来源：Beta 仍需检查存储、网络插件和运行时兼容性；应跟踪生产故障与性能开销。

证据：Kubernetes Blog

窗口内 / 容器评测

Docker Sandboxes：可复现的 AI 评测工作流

事件简介：Docker 介绍用 Sandboxes 隔离代理环境、固定依赖并重复执行 AI 评测。

技术机制：每次评测在受控容器中运行，输入、工具和环境可版本化，结果作为可比较工件保存。

限制与来源：沙箱不自动保证脱敏或完全确定性；需验证网络、GPU 和长任务边界。
