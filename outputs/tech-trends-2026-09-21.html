当前 GitHub Trending · 编码 Agent

Claude Code：在终端、IDE 与 GitHub 中执行代码库任务

简介：Claude Code 是 Anthropic 的 Agent 编码工具，面向希望让模型理解代码库并执行日常修改、解释和 Git 工作流的开发者。它可在终端、IDE 使用，也能在 GitHub 中通过 @claude 触发；输入是自然语言任务，输出是代码变更、命令结果和提交协作。

技术特点：项目把能力做成插件、命令和 Agent 扩展，并由官方 CLI、设置、权限和 Agent SDK 文档分别管理。它不是只生成代码的编辑器，而是能读取仓库、执行例行任务并通过 `/bug` 回报问题的工作循环；仓库同时提示 npm 安装已弃用，改用安装脚本、Homebrew 或 WinGet。

适用场景与价值：维护者可让 Agent 在真实仓库中完成测试、解释复杂模块或准备 Git 工作流，减少在聊天窗口复制文件的往返；这是基于其执行与集成入口的编辑判断。

限制与来源：使用会收集反馈、关联会话数据和用户反馈，需按官方数据使用政策评估；命令执行权限、模型可用地区和商业条款也由官方文档约束。来源：README、官方文档

简介：AstrBot 是开源的一体化 Agent 聊天机器人平台，服务个人、开发者和团队，把 AI 对话、知识库或自动化助手接入 QQ、企业微信、飞书、钉钉、Telegram、Slack 等 IM。它支持 WebUI/Web ChatUI，输入来自聊天消息、文件或插件，输出可回到对应平台。

技术特点：平台把多模态对话、Agent、MCP、Skills、上下文压缩和 Persona 放在插件体系中，并提供 1000+ 可安装插件。Agent Sandbox 隔离代码与 Shell 调用并复用会话资源；同时可接 Dify、百炼、Coze 等外部 Agent 平台，形成消息适配层与模型/工具层的组合。

适用场景与价值：团队可先用一个 IM 入口处理问答，再把知识库查询、工单自动化或内部脚本放进受控插件；消息平台无需各自重写模型调用，但沙箱和权限仍需按业务审核。

限制与来源：插件生态和外部平台连接扩大了供应链与凭据暴露面；README 只描述沙箱能力，没有独立安全审计结论。来源：中文 README：功能、平台与沙箱

当前 GitHub Trending · Agent 应用框架

Agent-Native：让 UI、Agent、MCP 与 CLI 共用一个 action

简介：Builder.io 的 Agent-Native 是 TypeScript 框架，面向要给自主 Agent 配套业务 UI 的开发者。应用能力以 action 定义，用户可在页面点击，Agent 可在对话中调用，外部 HTTP/MCP/A2A 客户端和终端脚本也能复用同一操作。

技术特点：defineAction() 为每个操作声明 Zod 输入模式和 run()；框架扫描 actions 目录并自动挂载。UI hooks、Agent 工具、HTTP 路由、MCP、A2A 与 pnpm action 都经过同一校验、权限和审计链。navigation/selection 只存语义 ID，view-screen 再从 SQL 读取最新记录，避免把整条数据复制进提示词。

适用场景与价值：客服或运营应用可让用户按钮与 Agent 执行同一“回复工单”操作，减少前端 API 和 Agent 接口各维护一份逻辑；轻量状态加实时回读也降低 Agent 依据过期页面内容操作的风险。

限制与来源：这是框架设计主张，尚无独立生产效果数据；开发者仍需实现授权、数据库和数据脱敏。来源：README、Actions 文档、上下文文档

当前 GitHub Trending（中文榜） · CDN 网络诊断

CloudflareSpeedTest：先测延迟丢包，再筛选 CDN IP

简介：CloudflareSpeedTest 面向需要改善网站访问质量的网络用户，测试 Cloudflare 或其他 CDN 公布 IP 段的延迟、丢包和下载速度，输出适合当前网络的 IPv4/IPv6 地址。它可在 Windows、Linux、macOS 或路由器上运行。

技术特点：默认流程先以 TCPing 并发测延迟，再按延迟和丢包条件过滤，最后逐个下载测速并按速度排序；参数可调线程数、端口、测速 URL、地区码、阈值和输出 CSV。HTTPing 模式还能从响应头读取 CDN 地区码，支持自定义 IP 段而非只测 Cloudflare。

适用场景与价值：家庭或边缘节点管理员可先筛掉高丢包地址，再把首行结果用于本地 DNS/Hosts 或代理配置，减少凭感觉反复换节点的时间；测速数据仍只代表当前网络和测试 URL。

限制与来源：作者提醒 Cloudflare 明文禁止代理套 CDN，WARP/UDP 不适用；HTTPing 属网络扫描，过高并发可能触发运营商或 CDN 限制，代理环境也会使结果失真。来源：README：流程、参数与限制
