i-have-adhd：让编码代理输出更易扫描

简介：这是一个可安装的 agent skill，面向容易被长答案淹没的编码者，要求代理先给结论、使用短段落并把细节置于后文。输入是任务上下文，输出是结构化回答。

适用场景与价值：代码审查或故障排查时，使用者先看到结论和受影响文件，再决定是否展开证据，减少在长日志中寻找行动项的时间。

限制与来源：效果依赖代理是否遵循指令，仓库没有独立可读性评测；不能把它当作 UI 无障碍工具。来源：官方 README

简介：editor 是开源 3D 建筑编辑器，提供本地 CLI、MCP 工具和面向人类与 AI agent 的工作流，输入是场景与几何数据，输出为可编辑建筑模型。

窗口内 / Kubernetes

Kubernetes 1.37：节点生命周期条件

事件简介：Kubernetes 官方介绍 1.37 的 Node Lifecycle Conditions，用更明确的条件表达节点何时不可调度、网络异常或正在排空，帮助控制器和运维工具共享状态语义。

技术机制：节点状态通过标准化 condition 字段与生命周期控制逻辑衔接，调度器、kubelet 和控制器据此更新 taint、驱逐和告警决策。

适用场景与价值：大集群可按条件区分暂时网络故障与真正失效，自动化系统能减少误驱逐并把告警指向具体生命周期阶段。

限制与来源：需要升级到 1.37 并检查自定义控制器是否依赖旧字段；文章描述的是版本能力，实际行为取决于发行版。来源：Kubernetes Blog

Lambda Managed Instances 支持 Graviton5

事件简介：AWS 为 Lambda Managed Instances 增加 Graviton5 EC2 实例，允许需要更长运行时间或更细容量控制的函数使用新一代 Arm 计算资源。

适用场景与价值：持续高负载的推理或数据处理函数可在保留 Lambda 部署体验的同时调整实例规模，避免完全迁移到自管集群。

限制与来源：需验证运行时、原生依赖和区域可用性；Arm 二进制兼容与成本效果必须用业务负载实测。来源：AWS News
