cat-catch：浏览器资源嗅探扩展

简介：cat-catch 是浏览器扩展，用于开发者和内容制作者检查网页加载的媒体、脚本与其他网络资源，并在浏览器内提供下载或分析入口。

限制与来源：跨域、加密流媒体和站点策略可能阻止读取；下载内容的版权与隐私责任由使用者承担。

证据：官方 README

edgetunnel：在 Edge/Serverless 中运行 V2Ray

简介：edgetunnel 将 V2Ray 协议栈封装到 Cloudflare Workers 等边缘或无服务器运行时，服务需要在没有常驻服务器时转发网络流量的用户。

当前 Trending（中文）/ 插件化媒体

MusicFree：本地插件化音乐播放器

简介：MusicFree 是面向 Android 与 HarmonyOS 的开源、无广告音乐播放器，播放器本身不内置音源，搜索、播放、歌单和歌词由插件提供，数据保存在本地。

技术特点：插件是约定接口的 CommonJS 模块，负责搜索、播放、专辑、作者、歌单和歌词函数；分页与缓存由播放器处理，插件可从本地或网络安装。

适用场景与价值：用户可以把不同公开音源适配成独立插件而不改播放器核心，播放器专注界面、缓存和本地隐私；这也便于搭建自己的离线音乐库。

限制与来源：项目作者称仍是不稳定的业余维护，第三方插件安全与版权数据不由项目负责；许可证为 AGPL-3.0。

证据：官方 README
