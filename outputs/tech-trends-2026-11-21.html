02 · phpAfterShell：文件锁无法撤销一次写到一半的会话更新

事件简介：Cloudflare 更新 PHP 会话攻击的防护说明；PHP 官方确认默认 files 会话处理器存在中断写入缺陷，修复版为 8.2.36、8.3.37、8.4.28、8.5.13。会话用来保存连续请求间的用户状态，这次问题出在保存过程，而非密码检查。

技术机制：原实现直接覆盖原文件，进程中途终止可能留下新数据前缀与旧数据尾部。文件锁只阻止并发访问，不会回滚已写字节；下次 session_start() 重新解析时，原本字符串里的内容可能被当成对象。修复先清空文件，并在清空失败时停止写入。

实际影响：编辑判断：运维应升级并重启全部 PHP worker，同时盘点上传进度功能及写入会话的大段用户输入。临时关闭上传进度只能移除一条入口，不能解决业务自行保存不可信会话内容的路径。

限制与来源：官方称远程执行还需适当写入中断与对象利用链；研究者另称可串联尚未完全披露的原生类缺陷，不能混成所有站点均可直接执行。WAF 已知模式阻断不等于修复，另三条新规则默认仅记录。

03 · RDS Oracle 主入口：切换主库时保留地址，连接仍须重建

事件简介：Amazon RDS for Oracle 新增 Primary Endpoint，为企业版数据库提供跟随当前主库的 DNS 名称。过去向同区或跨区副本执行计划切换后，团队要修改应用连接串或自管 DNS；现在可预先让应用使用这个自动提供的入口。

技术机制：主库与副本共享入口，切换时服务更新其指向，并在证书中加入该域名以支持主机名校验。连接池创建新连接时重新解析 DNS，就能连接新主库；文档建议客户端缓存有效期设低，例如六十秒。

实际影响：编辑判断：灾备演练可减少逐个应用改配置、走审批及协调发布的步骤，将验收集中到连接中断检测、重新解析和重连。这里处理主角色迁移，区别于本周 Oracle 维护前预备资源。

限制与来源：不保留已有会话或进行中的工作；非计划故障若采用 promote 将副本提升为独立实例，会得到新入口，仍须改连接串。SE2 不支持；跨区后原区域应用增加网络延迟。功能不另收费，覆盖商业区域。
